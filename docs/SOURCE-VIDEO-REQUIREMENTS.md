# 桌宠源视频要求

目标：让最终抠像边缘干净、人物大小一致、动作不被画幅裁切，减少后期反复处理。

---

## 一、最重要的 6 条

1. **纯绿背景，固定颜色**
   - 只用 `#00FF00`；
   - 不要深绿、黄绿、渐变绿、带纹理的绿幕；
   - 背景不能有阴影、地面、渐变、环境光。

2. **分辨率至少 1080p**
   - 推荐 `1920×1080`，16:9；
   - 最低 `1280×720`；
   - 24fps，固定帧率；
   - 高码率 MP4（H.264 / H.265），不要低清、不要严重压缩。

3. **角色边缘必须清晰**
   - 线稿边缘干净，不要柔光、发光、白雾、光晕；
   - 不要半透明边缘、不要景深虚化；
   - 白袍不要反绿，角色和绿幕之间边界要清楚。

4. **同一角色、同一机位、同一大小**
   - 所有动作使用同一张角色设定图做图生视频；
   - 固定机位：不推拉、不摇移、不旋转、不缩放；
   - 角色头顶到脚底占画面高度约 65%–70%；
   - 左右各留至少 10% 安全区。

5. **动作和道具必须完整在画内**
   - 头顶、脚底、袖子、手、书册、符纸都不能出画；
   - 符纸/书册一类横向道具，左右各留 8%–10% 余量；
   - 不要贴边，不要突然飞出画面。

6. **首尾可循环**
   - 首帧就是动作中段，不是站姿；
   - 末帧回到首帧姿态；
   - 不要在开头/结尾停顿、收手、回到标准站姿；
   - 8–12 秒最稳；工具支持 15 秒再生成 15 秒。

---

## 二、画面与动作要求

### 背景

- 纯 `#00FF00`，颜色均匀；
- 无阴影、无渐变、无地面、无桌面、无边框；
- 无烟雾、粒子、灰尘、火花、光效、法阵、能量波；
- 无文字、字幕、水印、logo、UI。

### 角色

- 原创 Q 版道系少女「小符」；
- 白色长发、银白狐眸、额前弯月符纹、白色道袍、银白小葫芦、赤脚；
- 约 2.3 头身；
- 每个动作的服装、发型、配色、饰品完全一致；
- 亮度、对比度、白平衡前后一致，不要忽明忽暗或偏色。

### 动作

- 动作速度中等，不要快速挥手、快速转头；
- 避免运动模糊把边缘拖脏；
- 不要生成半透明残影、重影、拖尾；
- 手部和道具不要与身体大面积重叠到看不清边界；
- 情感到位即可，不要夸张到变形。

### 镜头

- 固定机位，正面或轻微 3/4 侧；
- 全身完整；
- 不要俯视、仰视、广角畸变；
- 不要景深虚化，角色全程对焦。

---

## 三、交付格式

```text
容器：MP4
编码：H.264 或 H.265
分辨率：1920×1080（最低 1280×720）
画幅：16:9
帧率：24fps，固定帧率
码率：10–20 Mbps
音频：无
字幕：无
时长：8–12 秒；支持 15 秒可生成 15 秒
```

如果生成工具支持，优先给：

```text
PNG 序列（带 alpha）
或 ProRes 4444
或 WebM/VP9 + alpha
```

这样后期最干净；但普通 MP4 + 纯绿幕也可以。

## 五、各类动作的额外要求

| 动作类型 | 额外要求 |
| --- | --- |
| 空闲 | 动作幅度小；首尾姿态接近；不要睡觉符号 Z、文字 |
| 任务进行中 | 符纸/书册完整在画内；左右留 8%–10%；不要漂浮纸片飞出画面 |
| 任务完成 | 不要礼花、彩带、粒子；手部动作不要挡住脸 |
| 等待确认 | 符纸空白；不要对话框、问号、文字、UI |
| 耗时过长 | 不要时钟数字、文字、UI；沙漏/道具完整 |
| 余额警告 | 不要金币特效、账单、数字、文字；铜钱/钱袋完整 |

---

## 六、最容易被忽略、但最影响成片的三点

1. **绿色不纯 / 绿色有渐变** → 抠像后边缘发灰、发黑、发绿；
2. **角色边缘有白雾/柔光** → 抠像后边缘发糊，怎么调都像毛边；
3. **每个动作机位/缩放不同** → 人物大小不一致，无法靠后期统一。

只要这三点控制住，最终桌宠的边缘和大小会稳定很多。
