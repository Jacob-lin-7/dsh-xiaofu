# PRD · dsh-hex-pet（首版：A + B + C）

> 版本：v0.3（2026-10-26）· 状态：**M4 收尾 / M5 增强**（桌面 helper、设置页、生成任务已落地；剩平台验证与收尾项）
> 配套：[功能开关设计](./FEATURE-TOGGLES.md)、[借鉴清单](./BORROW.md)、[架构](./ARCHITECTURE.md)

## 1. 定位

**一只“装了就看得见、形象能自己换、菜单由自己定”的 DSH 桌宠。**

竞品把“桌宠”做成了功能堆叠（TTS、识屏、歌词、小游戏），代价是稳定性与可维护性；我们反过来：先把**可见、可控、可恢复**做好，再把“换形象”做成核心差异。

## 2. 目标与非目标

### 目标

| 目标 | 衡量方式 |
| --- | --- |
| 装上就能看到 | 全新安装后 60 秒内出现宠物（网页端） |
| 形象可自助 | 合法 petpack 导入成功率 ≥ 95%，中位耗时 < 10 秒 |
| 用户有决定权 | 每项功能可单独开关，菜单即时反映，重启保持，双端一致 |
| 出错可诊断 | 桌面端失败 5 秒内给出可读原因，并能一键回退网页 |
| 不伤宿主 | 插件引发的宿主崩溃 = 0（72 小时 soak） |

### 非目标（首版）

- 不做 Live2D、识屏、歌词/点歌、直播捕获、成就/小游戏、健康监督。
- 不做普通照片的**自动抠图**（透明图/绿幕可生成；抠图后置）。
- 不做宠物包市场/支付/账号体系。
- 不做移动端。

## 3. 用户与场景

| 用户 | 场景 | 关键诉求 |
| --- | --- | --- |
| 普通用户 A | 在 DSH 里工作，想让桌宠陪着 | 安装简单、不抢焦点、不卡 |
| 形象爱好者 B | 有自己的角色图/视频 | 能导入、能预览、能删除、能多只 |
| 极简用户 C | 只想要一只安静的宠物 | 关掉对话/余额/碎碎念，只留点击回应 |
| 创作者 D | 做宠物包分享 | 格式清晰、有校验器、能预览 |
| 插件作者 E | 想驱动桌宠 | 有文档化 API（后置阶段） |

## 5. 用户旅程

### J1 首次安装

安装插件 → 自动出现一只默认宠物（网页右上角）→ 右键菜单只有 5 项（对话、动作、形象、显示位置、设置）→ 设置页有“功能”区块可扩展。

### J2 导入形象

设置页「形象」→ 拖入 `.petpack.zip` → 校验（schema、素材、透明、比例）→ 预览（idle 循环 + 菜单预览）→ 安装 → 宠物切换为新形象 → 原形象保留可切回。

### J3 定制菜单

右键宠物 →「功能管理」→ 关闭“余额”“碎碎念”，打开“点击音效”→ 立即生效 → 重启后保持；或在 DSH 设置页做同样的事，并看到菜单预览。

### J4 桌面失败

桌面 helper 起不来 → 设置页顶部红色状态条：“桌面模式启动失败（退出码 X）：最后一行错误…” → 按钮「重试」「仅用网页」→ 点后者，宠物只在网页显示，不再重试。

### J5 恢复默认

用户把功能关得太多 → 右键「设置」或托盘 →「恢复默认功能」→ 二次确认 → 回到出厂菜单。

## 6. 功能需求

### 6.1 A 稳定性

#### R01 桌面健康状态可见

- 主机维护 `desktop.status`：`stopped | starting | running | failed`，附 `pid`、`lastExitCode`、`lastError`（最后 10 行 stderr）。
- 设置页顶部显示状态条；失败时提供「重试」「仅用网页」「复制诊断信息」。
- 连续失败 3 次进入熔断，不再自动重试，状态保持 failed。
- **验收**：手动 kill helper → 3 秒内状态变为 failed 并显示退出码；点「仅用网页」后不再拉起 helper，网页端正常。
- **v1 实现**：设置页状态条每 3 秒刷新；失败显示错误与「重试 / 仅用网页 / 复制诊断」；「仅用网页」会停止桌面并把显示位置改为网页。

#### R02 配置原子写 + 备份

- 所有写入走 `temp → fsync → rename`；保留最近 3 份 `.bak`。
- 读取失败时自动回退最近可用备份，并在 UI 顶部提示“已从备份恢复”。
- 保存失败返回字段级错误（哪个字段、为什么），UI 保留用户输入。
- **验收**：模拟磁盘只读 → 保存失败提示明确、原配置不变；手工写坏 JSON → 启动后自动恢复并提示。

#### R03 默认单实例

- 出厂默认一只宠物，`display: "web"`（若桌面可用且用户选择，再切 both）。
- 「添加宠物」是显式动作，不默认多开。
- **验收**：全新配置下只出现一只；设置页显示“1 只宠物”。

#### R04 不抢焦点、不挡全屏

- 检测到全屏应用、演示模式或截图工具时，**自动隐藏宠物**（可配置为“隐藏”或“仅穿透”），退出后恢复。
- 不在全屏应用上重钉 topmost；命中区仅在宠物身体范围生效，其余区域点击穿透。
- 适用范围：Windows、macOS、Linux X11；Wayland 尽力而为。
- **验收**：Win/macOS/X11 上进入全屏视频/游戏，1 秒内宠物隐藏、前台窗口不变；退出全屏后 2 秒内恢复；截图工具取景时宠物不挡命中。
- **2026-10-28 调整**：首版**不做**全屏/截图自动检测，改为右键手动隐藏（5/10/30 分钟、1 小时、自定义），避免维护进程白名单；自动检测后置到 v1.1 再评估。
- **v1 实现**：手动隐藏、`showInactive` 不抢焦点、命中区穿透已完成；全屏/截图自动检测按上述决定后置。

#### R05 多屏与混合 DPI（单屏保证，多屏实验性）

- 单屏：所有几何计算使用 DIP，显示/拖拽/回位准确。
- 多屏：支持负坐标屏、不同缩放、热插拔为**实验性**；跨屏异常时回退到主屏可见区，不允许丢宠或崩溃。
- 平台口径：Windows 10/11 x64、macOS 13+（arm64 + x64）完整；Linux X11 支持；Wayland 实验性。
- **验收**：单屏 100%/150%/200% 下拖拽/回位误差 < 2 DIP；双屏混合缩放不崩溃、可回主屏；拔屏后宠物可见。
- **v1 实现**：坐标统一 DIP；拖拽按光标所在显示器夹紧；新增 `display-removed` / `display-metrics-changed` 兜底，窗口完全离开所有显示器时回主屏中心。

#### R06 干净退出不复活

- 区分“用户主动退出”（专用退出码/消息）与“崩溃”；主动退出不重启。
- **验收**：右键退出 → 进程结束且 30 秒内不复活；kill -9 → 正常重启。
- **v1 实现**：helper 退出前发 `quit-pet`，宿主先把该宠物从 `desired` 移除再结束进程；崩溃仍走退避重启。

#### R07 LLM 失败隔离

- 碎碎念/对话的所有失败（超时、5xx、无模型、无凭证）只记录并展示气泡状态，不向上抛。
- 连续失败 3 次自动暂停该功能并提示，可手动恢复。
- **验收**：断网 10 分钟，宿主进程不退出；恢复网络后下一周期自动恢复（若未暂停）。
- **v1 实现**：`WhisperService` 调 OpenAI Chat Completions 兼容 endpoint（密钥仅读 `DSH_HEX_PET_LLM_KEY`），超时/网络/协议/空返回都转成结果对象；连续失败 3 次暂停，可手动恢复；自动周期与气泡展示待接。

#### R08 存储安全

- 只写自己的数据目录；删除前校验文件归属标记（manifest/owner）。
- 不触碰共享附件、不递归删除未知目录。
- **验收**：在数据目录放入无关文件 → 卸载/清理时不删除；删除宠物包只删除该包目录。

### 6.2 B 形象与素材

#### R09 petpack 导入

- 支持拖拽/选择 `.petpack.zip`；上限 50MB（可配）。
- 校验：manifest schema、id 唯一、引用文件存在、扩展名白名单、zip 路径安全、总解压大小上限、视频可解码、alpha 抽样、分辨率 16:9。
- 预览：idle 循环 + 菜单预览 + 元信息；确认后原子安装。
- 失败：逐条列出文件与原因，不产生半装状态。
- **验收**：合法包 10 秒内装好并出现在设置页；缺文件/黑底/竖图/超大包分别给出对应错误；重复 id 提示覆盖或改名。

#### R10 宠物包管理

- 列表：缩略图、名称、作者、版本、大小、启用状态。
- 操作：启用/停用、重命名显示名、删除（二次确认）、导出 zip。
- **验收**：删除后宠物消失且磁盘无残留；导出包可再次导入。
- **v1 实现**：列表/删除/导出 zip、显示名/显示版本、启用/停用已完成；停用包不出现在桌面切换菜单且不可绑定；author 只读，重复 id 覆盖策略 UI 未做。

#### R11 本地生成（v1；ffmpeg 首次使用时下载）

- 定位：插件在本机完成生成；**不随包分发 ffmpeg**，首次需要时按平台下载、校验、缓存；也支持复用系统 ffmpeg 或用户指定路径。
- 输入：透明 PNG/WebP、绿幕视频、已符合规格的透明 webm（合格则直通不重编码）。
- 流程：探测 ffmpeg → 缺失则提示下载（约 30–40MB，sha256 校验，落到 `$DSH_HOME/ffmpeg/<version>/`）→ 归一化（640×360、脚底 y=330）→ 微动/抠像/循环 → VP9-alpha → petpack → 走 R09 安装。
- 普通照片自动抠图：首版不做，UI 提示先抠图或拍绿幕；后续再评估宽松许可模型。
- 许可：优先 LGPL 构建；如使用 GPL 构建，展示许可与来源，不修改、不链接、仅以 CLI 调用。
- 失败/取消：下载失败可手动指定路径；生成可取消；临时文件清理。
- **验收**：无 ffmpeg 时首次生成能引导下载并成功；断网可手动指定；透明图 ≤ 30 秒、绿幕 ≤ 2 分钟；失败可读；插件包体积不因此增加。
- **v1 实现**：PNG/WebP 序列、ffmpeg 检测/下载、异步任务已完成；已符合规格的透明 webm 支持直通导入（不重编码）。
- **2026-11-01 范围收口**：R11 按实际使用范围完成——绿幕视频抠像与普通照片自动抠图明确不做（后置评估）。

#### R12 动画池扩展点

- `$DSH_HOME/dsh-hex-pet/animation-ext/<id>-ext.json`，`target` 指定条目，只追加不替换，追加后重跑校验，非法整段忽略。
- **验收**：扩展后原动画仍在；坏扩展不影响启动；`/anim` 能播追加动作。
- **v1 实现**：包列表与桌面 helper 启动时合并扩展；桌面右键「动作」可看到并播放追加动画；格式见 `docs/ANIMATION-EXT.md`。

#### R14 多形象

- 每只宠物可绑定不同 petpack；同包多实例共享素材。
- 切换形象不丢配置（大小/位置/人设保留）。
- **验收**：两只宠物不同形象同屏；切换后重启保持。

#### R15 表情包管理

- 设置页可添加/删除表情包、编辑描述、预览；文件落用户目录，配置自动同步。
- **验收**：加图后对话可选；删图后配置项自动失效不报错。
- **v1 实现**：客户端「表情」分区支持上传 PNG/JPEG/WebP/GIF（≤5MB）、名称/描述、预览、删除、描述再编辑；气泡可引用任一表情（`bubble.emojiId`），web 与桌面都显示。完整对话引用待做。

#### R39 格式规范 + 校验器

- 发布 `PETPACK_SPEC.md` + JSON Schema + `npx dsh-hex-pet validate <pack>`。
- **验收**：校验器对 10 个正例/10 个反例判断正确；错误信息含文件路径。
- **v1 实现**：规范与 Schema 已发布；CLI 支持 zip/目录与 `--json`，错误码稳定并带文件路径。

### 6.3 C 交互与易用

#### R17 左键动作可配置

- 选项：无 / 播放点击动画 / 打开 DSH / 打开对话。
- **验收**：切换后立即生效，双端一致。
- **v1 实现**：每只宠物 `clickAction`；设置页「交互」分区可改；桌面端「打开对话」会带 `?dsh-hex-pet=chat` 打开 DSH 并聚焦输入框。

#### R18 一键切换显示位置

- 菜单与设置页均可切：网页 / 桌面 / 两者 / 都不。
- **验收**：切换后 2 秒内生效，不重启。

#### R19 暂时隐藏

- 5 分钟 / 10 分钟 / 30 分钟 / 1 小时 / 自定义；到点自动恢复；重启后续计时。
- **验收**：设 1 分钟（测试模式）→ 到点自动出现；期间手动恢复会取消计时。
- **持久化**：桌面端隐藏状态写入 `hidden.json`，DSH 重启后仍按剩余时长继续隐藏（桌面宠物需重新点「启动」，插件不自动拉起）；helper 启动时带 `--hidden-until`，到点自行显示。

#### R20 点击音效

- 默认关；可换文件、调音量；双端一致；首次交互后解锁音频上下文。
- **验收**：开启后点击有声；静音/关闭后无声；不产生控制台错误。
- **v1 实现**：内置 Web Audio 合成点击音；支持上传 WAV/MP3/OGG（≤2MB）替换，音量 `sound.volume` 0–1；web 与桌面共用，桌面通过本地文件播放。

#### R22 多宠物避让

- 同角落多只宠物开机自动错开；用户手动摆放后尊重用户位置。
- **验收**：3 只同角落不重叠；拖动其中一只后重启保持。
- **v1 实现**：`/desktop/start {all:true}` 按角落累计高度垂直错开；有绝对 x/y 的手动位置不参与；只影响本次启动，不写回配置。

#### R23 宠物固定

- 开关：关闭随机漫游/转向，仅原地动作；主动点播不受限。
- **验收**：开启后 10 分钟不移动；点播“移动”仍可走。
- **v1 实现**：`motion.roam` 默认开；web 与桌面都会每 18–30 秒随机移动一次（拖动/菜单/隐藏时暂停）；关闭后完全固定，不写入配置。

#### R24 字体/字号

- 字体预设 + 字号 + 是否随宠物缩放；作用于气泡、提示、对话窗。
- **验收**：调整后即时生效；重启保持；不溢出气泡。
- **v1 实现**：`appearance.fontFamily/fontSize/scaleWithPet` 作用于客户端 overlay 菜单、关于、隐藏条与气泡；桌面气泡也按该字体渲染；桌面原生菜单仍用系统字体。

#### R25 托盘控制

- 显示/隐藏、打开设置、退出、重启桌面 helper；图标可配。
- **验收**：托盘退出后不复活；隐藏后可从托盘恢复。
- **v1 实现**：每只窗口独立托盘；菜单含显示/隐藏、打开设置、重载配置、退出本窗/全部；托盘图标可在设置页选择任一已安装形象包的 `preview`。

#### R26 桌面配置热重载

- 外部修改配置文件后 2 秒内自动生效，或提供“检测到变更，点击重载”。
- **验收**：改文件后不重启即可看到变化；无变更时不重复重载。
- **v1 实现**：`watchFile` 每 1 秒轮询 `main-config.json`，与最近一次写入/读取的 JSON 比较；有变化才同步桌面窗口，宿主自己写入不会触发重复重启。

#### R41 功能开关与菜单定制（P0）

- 能力注册表驱动：每项功能有 id、默认值、依赖、平台、菜单分组。
- 全局默认 + 单宠覆盖；隐藏/禁用两种模式；菜单顺序可调（P2）。
- DSH 设置页与桌宠端都可改；桌面端「功能管理」只放常用项。
- 保护项（设置）不可关闭；全关后仍有恢复入口。
- **验收**：见 [FEATURE-TOGGLES.md](./FEATURE-TOGGLES.md) 的 8 条验收用例。

## 7. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 空闲 CPU < 3%（单宠）；网页内存 < 150MB；启动 < 2s |
| 兼容 | Chrome/Edge/Firefox 最近两个大版本；Safari 用 mov；Windows 10/11 x64；macOS 13+（arm64 + x64）；Linux X11 支持、Wayland 实验性 |
| 安全 | 上传白名单、zip slip 防护、大小/解压比限制、无执行文件、路径穿越校验 |
| 隐私 | 本地优先；无遥测；生成不把原图传出本机 |
| 可访问性 | `prefers-reduced-motion` 时关闭挤压/粒子 |
| 国际化 | 首版 zh/en，文案集中管理，菜单标签走 i18n 表 |
| 可观测 | 结构化日志；诊断信息一键复制；错误码稳定 |

## 11. 验收指标

- 新安装到可见：< 60 秒（web）。
- petpack 导入：成功率 ≥ 95%，中位 < 10 秒。
- 菜单开关：8 条验收用例全过；双端一致 100%。
- 宿主稳定性：72h soak 无插件引发的崩溃；断网/断模型不影响宿主。
- 桌面失败：5 秒内可读错误 + 一键回退。

## 12. 风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| Electron 透明窗平台差异 | 高 | 先做技术预研；失败可见 + 网页兜底；不承诺全平台首发 |
| ffmpeg 许可与下载 | 高 | 不打包；首次使用时下载；优先 LGPL 构建；sha256 + 版本固定；可手动指定 |
| Safari alpha/黑底 | 中 | webm 为主；mov 可选；黑底检测提示 |
| zip 上传安全 | 中 | 白名单、大小/比例限制、路径校验、拒绝可执行文件 |
| 范围膨胀 | 高 | 严格按 A/B/C；D/E 需重新评审 |

## 13. 决策基线（2026-10-26 完成）

| 项 | 结论 |
| --- | --- |
| 名称 / scope | `dsh-hex-pet`；展示名「Hex 桌宠」；宠物角色名 Hex；单包不设 scope |
| 桌面透明窗 | 进首版、三平台；B+ 分级：Windows 10/11 x64 与 macOS 13+（arm64+x64）完整；Linux X11 支持、Wayland 实验性；多屏/混合 DPI 实验性，单屏保证；全屏/截图自动隐藏 |

| 许可证 | **代码 MIT**；素材单独许可（个人开发者，无企业/商业发行计划） |
| 上架市场 | **不赶首发**；v1.0 RC 后视稳定性上架，不设硬性日期 |
