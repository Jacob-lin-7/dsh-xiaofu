## 评分口径

| 字段 | 含义 |

## 不做清单

| 功能 | 原因 |
| --- | --- |
| 识屏问答 | 截图权限、隐私争议、同步链路 bug 多，投入产出比低 |
| 歌词/点歌/直播捕获 | 平台适配碎片化，受众窄，且容易牵连渲染稳定性 |
| 成就/小游戏/养成 | 与“桌面陪伴”主线漂移，只有个别竞品做 |
| 素材 AI 放大 | 需要 GPU/模型分发，首版不做；有需求可引导用户用外部工具 |
| 任意背景视频自动抠像 | 质量不可控，云端成本高；先只支持绿幕/透明素材 |

## 估算假设与风险

- 人日为净开发时间，不含需求评审、UI 设计与跨平台实机验证；桌面项实机验证建议按 +30% 预留。
- R05（多屏/DPI）和 R04（焦点/截图）是桌面路线的高风险项，建议先做技术预研再排期。
- R11（照片生成）依赖 ffmpeg 分发方案，若改为“仅导入 petpack”，可整项后置。
- R16（宠物包市场）涉及审核、版权、存储与分发，工作量按“产品项目”而非“功能”评估。
