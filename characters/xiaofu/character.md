# 小符（Xiaofu）

> 原创角色，不基于任何已有作品的角色。气质参考「道系、慢半拍、护短、能打」，但不复制任何现有角色的名字、发型、服装、武器、台词或配色组合。

## 一句话

Q 版白发道系少女，平时半睁眼、慢半拍，遇到事比谁都利落。

## 外形

- 头身比：约 2.3–2.5 头身（当前参考图的实际比例）
- 发型：白色长发，发尾银白渐变，一侧编一条细辫
- 眼睛：银白狐眸，平时半睁；认真时睁圆
- 标志：额前一枚弯月符纹
- 服装：纯白长道袍，白色内衬，长裙摆；不露裤子
- 配饰：腰间银白色小葫芦
- 脚：赤脚，脚落地（第一版不悬浮）
- 气质：平静、有点困、慢半拍、轻微傲娇

## 配色

| 用途 | 颜色 |
| --- | --- |
| 主色 | 白 `#F7F7FA` |
| 阴影 | 银灰 `#C9CDD6` |
| 描边 | 浅灰 `#8A8F98` |
| 眼睛/符纹 | 月银 `#E8EAF0` |

> 纯白在 640×360 容易糊，视频里必须保留银灰阴影和清晰描边，不要全部糊成一片白。

## 性格

- 说话慢半拍，做事不拖
- 护短，自己人受欺负会突然认真
- 偶尔冒一句方言口癖，但不写成具体方言
- 对符纸、罗盘、木剑这类东西很熟
- 不喜欢解释，喜欢直接做完
