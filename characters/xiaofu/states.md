# 小符 · 动作映射与气泡

> 设置页里叫「动作映射」：固定事件 → 选择动作 → 设维持时间；台词统一在「气泡」页设置。
>
> 动作只播一次/循环，文字由气泡单独渲染，不烧进视频。

## 固定事件

设置页只列这 6 个，不能自由增删：

| 事件 | 含义 | 动作文件 | 播放 | 气泡示例 |
| --- | --- | --- | --- | --- |
| 空闲 | 没有任务 | `idle.webm` | 无缝循环 | 无 |
| 任务进行中 | 开始跑任务 | `state-working.webm` | 6 秒循环 | 正在处理… |
| 任务完成 | 任务结束 | `state-done.webm` | 2.4 秒循环 | 搞定啦 |
| 需要批准请求 | 等待审批 | `state-approval.webm` | 8 秒循环 | 这里需要你确认一下 |
| 耗时过长 | 单次任务超时 | `state-alert-time.webm` | 6 秒循环 | 这一步有点久了… |
| 余额警告 | 单次任务 token 超阈值 / 任一币种余额低于阈值 | `state-alert-cost.webm` | 9 秒循环 | 余额/消耗提醒 |

## 维持时间

- `0` = 一直保持这个动作，直到下一个事件；
- 正数 = 保持 N 秒，然后自动接回**空闲动作**。

例子：任务完成动作设为 `5` 秒：

```text
任务完成 → 播 5 秒庆祝动作 → 自动接回空闲动作
```

## 余额警告

- 单次任务 token 阈值：默认 `20000`
- 币种阈值：默认 `CNY ≤ 10`、`USD ≤ 1`，可增删、每个币种单独判断
- 满足任一条件即触发；**每个任务只触发一次**
- 余额来源：DSH 当前账户总余额（充值 + 赠送钱包，按币种分别汇总）
- 维持时间：`0` = 一直到下一个任务动作；正数 = 循环 N 秒后接回空闲动作

## 角色选择

动作映射顶部有角色下拉：

- 选中小符，编辑的是小符的动作映射；
- 切换到其他角色，编辑的是那个角色的映射；
- 映射按角色分别保存，不会互相覆盖；
- 「触发」只对当前正在使用的角色生效；编辑别的角色时按钮禁用。

## 动作库

动作的上传和改名都在「动作映射」上方的「动作库」里，**动作归属当前角色**，不在每个事件行里：

- **上传动作**：选透明 `.webm` / `.mov`，上传后自动加入当前形象包；
- **改名**：每个动作一行输入框，改完所有映射同步；
- 内置动作显示中文名，上传动作默认显示文件名，可改成任意名字；
- 映射行只负责选动作，不再重复配动作名。

## 动作选择

- 每个事件先选一个动作；选择框后面的 **+** 可再加一个，**×** 移除；
- 一个事件可以挂多个动作；进入该状态后按顺序轮流播放：每个动作完整播一遍，再切下一个，最后回到第一个；
- 只选一个动作时，就是原来的单动作循环；
- 动作下拉来自当前形象包的全部动画；
- 内置动作显示中文名（空闲、任务进行中、等待确认等），上传动作默认显示去掉扩展名的文件名；
- 每行「动作名」输入框可以直接改显示名，改完下拉里也同步；
- 留空会恢复默认名；
- 自己上传的动作只要进 manifest 的 `animations`，就会出现在下拉里。

## 气泡与台词

台词统一在设置 →「对话」里按事件设置：

- 点击时
- 空闲
- 任务进行中
- 任务完成
- 需要批准请求
- 耗时过长
- 余额警告

每个事件一个文本框，**每行一句**；同一个事件有多行时，按顺序轮换：

- **对话时长**：每句显示多久；
- **对话间隔**：两句之间隐藏气泡多久，间隔期间无对话、无气泡；
- 状态持续时，这套「显示 → 间隔 → 下一句」会一直循环，直到状态结束。

气泡样式在同一页上方：内置多种样式，也可以上传 png/svg/webp 自定义气泡图。

- **Web**：宠物头顶 HTML 气泡。
- **桌面**：Electron 窗口内同一个气泡组件。
- **不进视频**：视频只有透明角色；气泡由宿主按动作显示/隐藏。

气泡建议：

- 动作色点：进行中=绿，审批=黄，完成=蓝/绿，异常=橙红；
- 一行短文案；
- 详情：`已用 3m12s`、`本轮 18.4k token`；
- 审批加「去处理」按钮；
- 完成/异常 5–8 秒自动收起；审批常驻到处理。

## 循环动作怎么设计

- 首帧就是动作中段，不是站姿；
- 首尾帧逐帧相同，但都是动作中段；
- 不回到站姿、不收手、不在首尾停顿；
- 6–8 秒一条；
- 状态持续多久，动作就循环多久。

## 当前实现

- 设置页可编辑 6 个固定事件的启用、动作、维持秒数；
- 台词在「气泡」页按事件设置，动作映射里不再单独填气泡；
- 每行有「触发」测试；
- `/state/trigger`、`/state`、`/state/clear` 已可用；
- DSH 自动事件（running / waiting / done / 超时 / token）还没接，当前靠手动触发或外部调用。
