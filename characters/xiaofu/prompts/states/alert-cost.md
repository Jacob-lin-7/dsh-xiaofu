# state-alert-cost · 单轮消费 token 过多（6 秒无缝循环）

先粘 `base.md`，再粘下面这段。**首帧就是倒葫芦的中段，循环，不回到站姿。**

```text
动作：发现 token 花太多了，反复倒葫芦、找余额，6 秒无缝循环。

首帧：双手捧着腰间的银白色小葫芦，葫芦口朝下，正在晃；眼睛盯着葫芦，表情不安；不要站直，不要双手垂下。
0–2 秒：把葫芦倒过来晃两下，像在确认里面是不是空了，肩膀微微缩着。
2–3.5 秒：把葫芦凑近看，眼睛睁大，嘴巴微张；另一只手拍了拍袖口和腰间，像在找还有没有剩下的。
3.5–5 秒：找不到，肩膀垮下来，叹一口气，抬手擦汗，小葫芦垂在手里。
5–6 秒：重新把葫芦捧回胸前、口朝下晃起来，回到首帧姿态，准备继续循环。

首帧和末帧必须逐帧相同，且都是倒葫芦的中段。不要回到标准站姿，不要在首尾停顿。
全程原地，不位移、不转身、不出画。不要生成金币、账单、数字、文字、UI、烟雾、粒子或光效；消费感只靠倒葫芦、找东西、震惊和叹气。
```
