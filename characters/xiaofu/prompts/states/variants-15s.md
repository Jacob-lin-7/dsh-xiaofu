# 小符 · 状态动作 15 秒变体提示词

> 每个状态两条新变体，风格分别偏「活泼 / 困倦 / 认真 / 傲娇 / 无奈」等不同方向。
>
> 生成时先粘「通用前缀」，再粘对应动作段落。每条 15 秒，24fps，无缝循环。

---

## 通用前缀（每条都要）

```text
16:9 视频，纯绿幕背景 #00FF00，颜色统一，无阴影、无渐变、无杂物、无地面、无边框。
角色：原创 Q 版道系少女「小符」，约 2.3 头身。白色长发，发尾银白渐变，一侧编一条细辫；银白狐眸；额前一枚弯月符纹；纯白长道袍，白色内衬，长裙摆，腰间银白色小葫芦；赤脚，双脚落地。
角色完整居中：头顶约在画面 20%，脚底约在 85%，左右在 25%–75%；任意部位距画幅边缘至少 10%，全程不能被裁切。
固定机位，不推拉、不摇移、不旋转、不缩放。角色大小、比例、服装、配色全程完全一致。
原则：每一帧的亮度以及前后人物颜色保持一致；不要突然变亮/变暗、偏色或换色。
画面无文字、无字幕、无水印、无 logo；符纸必须是空白纸片，不能有任何字。
不要烟雾、粒子、光效、光环、火花、法阵、能量波；动作只靠身体、表情和实体道具完成。
```

**循环规则（每条都适用）：**

```text
15 秒无缝循环。
首帧就是动作中段，不是站姿；首帧和末帧逐帧相同，但都是动作中段。
不回到标准站姿、不收手、不在首尾停顿。
全程原地，不位移、不转身、不出画。
```

# 1. 空闲

## idle-3 · 打哈欠伸懒腰（困倦、慢节奏）

```text
动作：站着打哈欠、伸懒腰，15 秒无缝循环。

首帧：双手半举在胸前，肩膀微微耸起，眼睛半睁，像刚伸到一半；不要站直，不要双手垂下。
0–5 秒：慢慢把双手举过头顶，伸一个大懒腰，胸口打开，发尾和小葫芦跟着向上提；嘴巴张开打哈欠，眼睛闭上。
5–10 秒：手臂放下一半，肩膀松下来，眨两次眼，头轻轻歪向一侧，像还没睡醒；右脚小幅度点地。
10–15 秒：重新把双手举回胸前半举的位置，肩膀耸起，眼睛半睁，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是伸懒腰中段。不要回到站姿，不要收手。
不要生成床、枕头、文字或睡眠符号 Z。
```

## idle-4 · 靠葫芦打盹（安静、慢半拍）

```text
动作：站着打盹，身体轻轻晃，15 秒无缝循环。

首帧：身体微微向右侧倾，重心压在右脚，眼睛闭着，双手自然垂在身前，小葫芦贴在腰侧；像已经睡着了一半，不要站直。
0–5 秒：身体向右轻轻晃两下，头慢慢低下去，发尾跟着摆；呼吸变慢，胸口轻微起伏。
5–10 秒：头突然一点，像被自己惊醒，眼睛睁开一条缝，眨两下，左右看了一下，又慢慢闭上。
10–15 秒：身体重新向右倾，头低下去，双手垂在身前，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是打盹中段。不要躺下，不要位移，不要生成 Z、枕头、文字。
```

# 2. 任务进行中

## work-2 · 摊开符阵（认真、利落）

```text
动作：把空白符纸一张张摊开、排好，再逐张确认，15 秒无缝循环。

首帧：半蹲，左手压着一叠空白符纸，右手正把一张符纸按到地面上；眼睛盯着纸面，表情认真。不要站直，不要双手垂下。
0–5 秒：右手快速把三张符纸依次摊开，排成一条弧线；左手压住纸角，袖口和小葫芦跟着晃。
5–10 秒：站起来一点，目光从左到右扫过符纸，右手食指逐张点过去，像在核对；点头一次。
10–15 秒：重新半蹲，左手收起两张符纸，右手把最后一张按回地面，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是排符纸中段。不要回到站姿，不要收手。
符纸是空白纸片，不要出现文字、符号、法阵或光效；不要生成漂浮的纸。
```

## work-3 · 卷袖翻册（干脆、忙碌）

```text
动作：卷起袖子、翻一本空白册子、用葫芦压住页角，15 秒无缝循环。

首帧：双手正在把左袖往上卷，右臂夹着一本空白纸册，眼睛看着袖口；身体微微前倾，不要站直。
0–5 秒：把两只袖子都卷到手肘，拍两下袖口，拿起纸册翻开到中间。
5–10 秒：快速翻两页，眉头微皱，右手食指在空白页上划了一下；把腰间小葫芦取下来压住页角。
10–15 秒：把葫芦拿回腰间，合上册子夹回右臂，重新开始卷左袖，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是卷袖中段。不要回到站姿，不要收手。
册子和符纸必须是空白纸，不要出现文字、图案、法阵或光效。
```

# 3. 任务完成

## done-2 · 收符纸拍整齐（满足、利落）

```text
动作：把散开的空白符纸收成一叠、在掌心拍齐，满意地点头，15 秒无缝循环。

首帧：双手正把最后两张符纸往一起收，纸叠在胸前，眼睛看着纸边；身体微微前倾，不要站直。
0–5 秒：把符纸收齐，双手在掌心轻轻拍两下，把纸边对齐；肩膀放松。
5–10 秒：把纸叠抱在胸前，眼睛弯起来，得意地点头一次；小葫芦轻轻晃。
10–15 秒：把纸叠重新分开一点，做出继续收纸的动作，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是收纸中段。不要回到站姿，不要收手。
不要礼花、彩带、粒子、光晕、文字或 UI。
```

## done-3 · 倒茶犒劳自己（松弛、慢节奏）

```text
动作：从银白小葫芦里倒出一杯茶，慢慢喝一口，放松肩膀，15 秒无缝循环。

首帧：左手托着一只空白小茶杯，右手正把葫芦口凑到杯沿；眼睛看着杯子，肩膀松着。不要站直，不要双手垂下。
0–5 秒：把茶倒进杯子，收起葫芦，双手捧杯，轻轻吹一下。
5–10 秒：抿一口，眼睛闭上，肩膀放下来，长出一口气；头轻轻歪一下。
10–15 秒：把杯子放低，重新拿起葫芦，做出继续倒茶的动作，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是倒茶中段。不要回到站姿，不要收手。
不要生成茶壶、桌子、椅子、蒸汽、热气、文字或 UI；茶杯是空白小杯。
```

# 4. 需要批准请求

## approval-2 · 抱臂等待（傲娇、不耐烦）

```text
动作：抱着手臂等确认，脚尖点地，眉毛越挑越高，15 秒无缝循环。

首帧：双臂抱在胸前，右手手指在左臂上轻敲，右脚脚跟抬起、脚尖点地；眼睛看着前方，眉毛微挑。不要站直，不要双手垂下。
0–5 秒：右脚不耐烦地点两下地，头歪向一侧，嘴角微微下撇。
5–10 秒：抬起右手，用食指朝前方点了两下，像在催；又抱回手臂，叹一口气。
10–15 秒：重新开始用手指敲手臂，脚尖点地，眉毛挑起来，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是抱臂中段。不要回到站姿，不要收手。
不要生成对话框、问号、文字、时钟或 UI。
```

## approval-3 · 举符纸示意（认真、耐心）

```text
动作：双手举着一张空白符纸，朝前方递了递，再指指符纸，等对方确认，15 秒无缝循环。

首帧：双手在胸前举着一张空白符纸，纸面朝向镜头，眼睛从纸后看向前方；身体微微前倾。不要站直，不要双手垂下。
0–5 秒：把符纸往前递近一点，眉毛抬起，像在问「这样可以吗」。
5–10 秒：用另一只手的食指点了点符纸右下角，再摊开手，做出「你看」的动作。
10–15 秒：把符纸收回胸前，重新举稳，眼睛看向前方，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是举纸中段。不要放下符纸，不要回到站姿，不要收手。
符纸必须是空白纸片，不要出现任何文字、符号、印章或 UI。
```

# 5. 耗时过长

## timeout-2 · 看沙漏（无奈、慢节奏）

```text
动作：托着一个小沙漏看时间，翻过来又翻过去，叹口气，15 秒无缝循环。

首帧：左手托着一个空白沙漏，右手食指正点在沙漏上端；眼睛盯着沙漏，眉头微皱，肩膀塌着。不要站直，不要双手垂下。
0–5 秒：把沙漏翻过来，看沙子往下落，脚尖轻轻点地，叹一口气。
5–10 秒：把沙漏举到眼前，眯起眼睛看，摇了摇头；又翻回去，肩膀更垮。
10–15 秒：把沙漏收回胸前，右手食指重新点在上端，眼睛盯着，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是看沙漏中段。不要回到站姿，不要收手。
不要生成数字、时钟、文字、UI 或光效；沙漏里不要有发光的沙子。
```

## timeout-3 · 叉腰踱步（焦躁、活泼）

```text
动作：双手叉腰，在原地来回换重心，抬头看斜上方，摊手，15 秒无缝循环。

首帧：双手叉腰，右脚脚跟抬起、脚尖点地，身体微微向左侧倾；眼睛看向斜上方，脸颊鼓起。不要站直，不要双手垂下。
0–5 秒：换重心到左脚，右脚点地两下，头跟着转向另一侧，像在来回踱步。
5–10 秒：抬起一只手朝斜上方指了指，又摊开手，像在问「还要多久」；小葫芦跟着晃。
10–15 秒：重新双手叉腰，鼓起脸颊，脚尖点地，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是叉腰中段。不要回到站姿，不要收手。
全程原地，不要真的走出画面。不要生成时钟、数字、文字、问号、UI 或粒子。
```

# 6. 余额警告

## balance-2 · 倒葫芦数铜钱（心疼、夸张）

```text
动作：把银白小葫芦倒过来抖，倒出几枚铜钱，一枚枚数，越数越心疼，15 秒无缝循环。

首帧：双手捧着倒过来的小葫芦，葫芦口朝下，正抖到一半；眼睛盯着葫芦口，肩膀缩着。不要站直，不要双手垂下。
0–5 秒：用力抖两下，几枚铜钱落在另一只手的掌心里；把葫芦放下，低头数钱。
5–10 秒：一枚一枚拨着铜钱数，眉头越皱越紧，嘴巴微张；抬头看一眼空葫芦，摇头。
10–15 秒：把铜钱倒回葫芦里，重新把葫芦倒过来，做出继续抖的动作，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是倒葫芦中段。不要回到站姿，不要收手。
不要生成金币特效、账单、数字、文字、UI、粒子或光效；铜钱是普通的小铜钱。
```

## balance-3 · 捂钱包看空符纸（无奈、慢半拍）

```text
动作：捂住腰间的钱袋，又抽出一张空白符纸看，确认「真的没了」，叹气，15 秒无缝循环。

首帧：左手捂着腰间的空钱袋，右手拿着一张空白符纸，眼睛看着纸面，嘴角向下。不要站直，不要双手垂下。
0–5 秒：把符纸翻过来看背面，又翻回来，眉头皱起；手指捏了捏空钱袋。
5–10 秒：把符纸举到眼前，眯起眼睛看，摇了摇头；肩膀垮下来，叹了一口气。
10–15 秒：把符纸折好塞回袖口，重新捂住钱袋，眼睛看向前方，回到首帧姿态，准备继续循环。

首帧和末帧逐帧相同，且都是捂钱袋中段。不要回到站姿，不要收手。
符纸必须空白，钱袋是普通布钱袋。不要生成数字、账单、文字、UI、粒子或光效。
```

## 生成提醒

- 每条都先上传**同一张小符角色图**，用图生视频，不要纯文生视频；
- 15 秒如果工具上限只有 10 秒，先生成 10 秒，再把首尾多留 1 秒，后期接成循环；
- 不要加烟雾、粒子、光效，后期抠像会干净很多；
- 每条至少出 2 个候选，优先选绿幕干净、角色不出画、首尾姿态接近的。
