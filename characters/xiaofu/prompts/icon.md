# 小符 · 桌宠图标提示词

目标：1024×1024 正方形应用图标，缩小到 32px / 16px 仍能看清。

## 正向提示词

```text
正方形应用图标，1:1，1024×1024，透明背景。

原创 Q 版道系少女「小符」的半身头像，不是全身站姿：
人物从画面下缘探出上半身，身体前倾，头大身小，歪头，单眼 wink；
一只手举到脸旁比耶/招手，另一只手抱着银白色小葫芦；
白色长发，发尾银白渐变，一侧细辫；银白狐眸；额前弯月符纹；
纯白道袍领口，银色小葫芦，赤脚不出现。

构图：头部和肩膀占画面 80%–85%，人物完整居中，四周留 6%–8% 安全边；
深墨蓝圆形徽章底，圆形刚好填满正方形，圆外透明；
背后一枚很淡的银白弯月，像从月牙后面探头。

风格：可爱、干净、扁平化、粗轮廓、少细节、强对比；
白色头发和白色道袍用浅灰/银色描边区分；
主色只有白、银、浅灰、深墨蓝；
适合 Windows 任务栏 / 托盘小图标，缩到 32px 仍能辨认脸、月牙和葫芦。

不要文字、不要 logo、不要水印、不要边框、不要渐变背景、不要绿色。
```

## 负向提示词

```text
全身站立，直直立正，双腿，脚，复杂发丝，细线条，过多配饰，
真实比例，写实风，厚涂，3D，景深，柔光，发光，烟雾，粒子，

```

## 生成建议

- 出 4 张候选，优先选**脸大、轮廓清楚、深色底、白头发对比强**的；
- 生成后缩到 32×32 和 16×16 检查：还能看出「白发 + 月牙 + 葫芦」才算合格；
- 最终交付：`1024×1024 PNG`，圆外透明；
- 文件命名建议：`characters/xiaofu/icon.png`；
- 放进形象包后，在 `manifest.json` 加：
  ```json
  "icon": "icon.png"
  ```
  托盘会优先使用这个方形图标，而不是竖版 preview。


## 当前托盘图标为什么糊

1. 之前托盘直接拿**竖版 preview** 缩成 16×16；
2. 人物全身细节在 16px 下全糊；
3. 代码又强制 `resize({width:16,height:16})`，等于先压到最低分辨率。

现在已经去掉强制 16px 缩放；换成这张正方形图标后会清楚很多。
